# RedFaradaySpur

This mod turns [Faraday Spur](https://riskofrain2.wiki.gg/wiki/Faraday_Spur) into a legendary (red) item instead of an uncommon (green) item. To compensate, it gets a couple buffs to try to keep it exciting in its new tier:

- charging speed increased by **+60%**
- shockwave damage increased to **1000% (+700% per stack)**, up from 400% (+280% per stack).

These stat changes can be adjusted or disabled in the config if you wish.

![faraday-spur](https://raw.githubusercontent.com/SSM240/RoR2RedFaradaySpur/refs/heads/main/github-imgs/faraday-spur.jpg)

### Why?

As a green item that shows up in many runs, I feel that Faraday Spur is far too game-warping. The combination of the sheer amount of movement speed you get at max charge (+160% from one stack of a green???), the pretty underwhelming shockwave when you jump, and the amount of time it takes to recharge after jumping, means you're borderline forced into a playstyle of avoiding jumps at all costs, which clashes poorly with other jumping-based items in the same tier, like Hopoo Feather and especially Wax Quail.

One option is to keep it as a green and just adjust its stats to be less extreme, but I feel that's the more boring option (plus [FaradaySpurTweaks](https://thunderstore.io/c/riskofrain2/p/mwmw/FaradaySpurTweaks/) can already handle that). I don't necessarily hate how the item is designed, I just want it to show up less often.

Shifting it up into a red and adjusting its stats to match feels like a clean solution to this problem. It'll still be playstyle-defining when you have it, but that's what red items are meant for. And I think it's cool to have a more substantial horizontal mobility item in the red item pool, which is pretty limited currently.

### Compatibility

The mod has full support for [Quality](https://thunderstore.io/c/riskofrain2/p/Goorakh/Quality/). It doesn't currently adjust any quality effects, but all versions of Spur will have the new tier and base effect buffs.

![quality](https://raw.githubusercontent.com/SSM240/RoR2RedFaradaySpur/refs/heads/main/github-imgs/quality.png)

The new damage stats will also be reflected in the stats display for [LookingGlass](https://thunderstore.io/c/riskofrain2/p/DropPod/LookingGlass/) if that is installed.

Everyone (server + client) should have this mod in multiplayer, with the same config.

As always, if anything is broken, ping me on Discord (`ssm24`) or open an issue on GitHub. Otherwise, enjoy :D
