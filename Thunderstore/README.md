# RedFaradaySpur

This mod turns Faraday Spur into a legendary (red) item instead of an uncommon (green) item. To compensate, it gets a couple buffs to try to keep it exciting in its new tier:

- charging speed increased by **+100%**
- shockwave damage increased to **1000% (+700% per stack)**, up from 400% (+280% per stack).

These stat changes can be adjusted or disabled in the config if you wish.

### Why?

I personally feel like Faraday Spur is way too playstyle-warping as a green item, especially because it gives so much speed you kind of _have_ to play into it. One option is to just nerf its stats to be less extreme, but I felt that's the more boring option (plus [FaradaySpurTweaks](https://thunderstore.io/c/riskofrain2/p/mwmw/FaradaySpurTweaks/) can already handle that) and doesn't necessarily solve the frustration of how badly it clashes with other jumping-based items in the same tier, especially Wax Quail, probably my personal favorite item in the game.

Shifting it up into a red and adjusting its stats to match feels like a more fun solution. It'll still be run-defining when you have it, but that's what red items are meant for. And I think it's cool to have a more substantial horizontal mobility item in the red item pool (currently that's only Growth Nectar, which is pretty incidental, and Hardlight Afterburner, on _some_ characters).

### Compatibility

The mod has full support for [Quality](https://thunderstore.io/c/riskofrain2/p/Goorakh/Quality/). It doesn't currently adjust any quality effects, but all versions of Spur will have the new tier and base effect buffs.

![quality](https://raw.githubusercontent.com/SSM240/RoR2RedFaradaySpur/refs/heads/main/github-imgs/quality.png)

The new damage stats will also be reflected in the stats display for [LookingGlass](https://thunderstore.io/c/riskofrain2/p/DropPod/LookingGlass/) if that is installed.

Everyone (server + client) should have this mod in multiplayer.

As always, if anything is broken, ping me on Discord (`ssm24`) or open an issue on GitHub. Otherwise, enjoy :D
