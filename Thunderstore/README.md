# RedFaradaySpur

This mod simply turns Faraday Spur into a legendary-tier item instead of an uncommon. To compensate, by default it gets a couple buffs to bring it up to the level of other legendaries:
- charging speed increased by +75%
- shockwave damage doubled to 800% (+560% per stack), up from 400% (+280% per stack)
These changes can be adjusted in the config if you wish.

Everyone should have this mod in multiplayer.

As always, if anything is broken, ping me on Discord (`ssm24`) or open an issue on GitHub. Otherwise, enjoy :D
